This study leverages machine learning models to predict carbon sequestration and quantify tree species diversity across ten forests in Nigeria. In addition, it implements a practical, interactive dashboard that allows stakeholders to access real-time predictions, monitor forest conditions, and support informed decision-making. Furthermore, the study employs model-based ordination of species composition using Generalized Linear Latent Variable Models (GLLVM) in R to uncover latent ecological gradients, providing deeper insights into forest community structure and ecological drivers.
